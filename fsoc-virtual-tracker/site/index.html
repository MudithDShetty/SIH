Virtual camera tracking for coarse FSOC alignment

BeamLock is a real-time PAT sandbox: detect a beacon, Kalman-track it, slew an AZ/EL camera under turbulence, recover with raster search, and hand off to a Fine 4-QD mock when Link Readiness is high.

What it does

  • Closed-loop AZ/EL coarse PAT
  • Cn² physics channel + SNR readiness
  • Classical or AI+fusion detection
  • Raster re-acq · Fine handoff ≥0.7

Scenarios

  • Calm — baseline lock
  • UAV — moderate channel
  • Stress — lose → search → re-lock

Evidence

  • Monte Carlo Tacq: UAV/Stress 40/40 within ESTOL <60 s
  • Matched-seed Classical vs AI logs
  • Streamlit report + PDF from desktop

Run the full desktop prototype (recommended for evaluation)

  1. Clone: git clone https://github.com/MudithDShetty/SIH.git
  2. cd SIH/fsoc-virtual-tracker
  3. Create venv, then pip install -r requirements.txt
  4. Run: python main.py
  5. Presets: F1 Calm · F2 UAV · F3 Stress · T Classical/AI+fusion · L force loss · B multi-beacon
  6. Report: streamlit run report.py
